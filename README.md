# JalSanrakshak AI 🌧️💧  
### Smart Rooftop Rainwater Harvesting & Recharge Planner

JalSanrakshak AI is an AI-powered decision-support system designed to assess rooftop rainwater harvesting (RTRWH) and artificial groundwater recharge potential for any location. Developed as part of **Smart India Hackathon 2025**, the system converts satellite data, rainfall statistics, and groundwater information into **actionable, ready-to-implement harvesting plans**.

## 🚀 Problem Statement
Design and develop an application for **on-spot assessment of rooftop rainwater harvesting and artificial recharge potential**, including:
- Estimation of harvestable rainwater volume  
- Suitability of recharge structures  
- Cost, feasibility, and impact analysis  

---

## 💡 Solution Overview
JalSanrakshak AI provides a **web and mobile-based platform** that:
- Automatically analyzes rooftop and land area using satellite imagery
- Integrates real-time and historical rainfall, soil, and groundwater data
- Applies ML models to estimate runoff, water potential, and optimal recharge structures
- Generates **interactive dashboards and downloadable feasibility reports**

The system removes guesswork and transforms awareness into **clear, data-backed action plans**.

## 🧩 System Architecture

### User Inputs
- Location (auto-detected or manual)
- Satellite imagery for rooftop/ground area

### Data Integration
- IMD Rainfall API  
- CGWB Groundwater API  
- Soil & Aquifer Data APIs  
- Geocoding (Google / Mapbox)

### ML Processing
- Runoff coefficient estimation  
- Harvestable water volume calculation  
- Structure recommendation (RTRWH / AR)  
- Cost and payback analysis  

### Output
- Interactive dashboard  
- Downloadable feasibility & impact report
